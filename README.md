# Typing Speed Test

A lightweight typing speed test built with plain HTML, CSS, and JavaScript.

## Features

- Starts the timer on the first typed character
- Compares the typed text against the target text in real time
- Shows visual typing states for idle, active, error, and success
- Calculates errors, accuracy, WPM, and WPS
- Stores every completed round in the results table

## Run locally

Open `index.html` directly in a browser, or serve the folder with any static server.

```bash
python3 -m http.server 5501
```

Then open `http://localhost:5501`.
